# 디자인: 레퍼런스 → 토큰 → 구성 요소

## 레퍼런스에서 뽑을 것

브라우저로 레퍼런스를 열고 스크린샷을 2~3장 찍는다 (첫 화면, 스크롤 중간, 폼/대시보드 부분).

| 항목 | 볼 것 | 토큰 예 |
|---|---|---|
| 주요 색 | 버튼·강조 색, 그라디언트 방향 | `--blue`, `--grad` |
| 어두운 면 | 사이드바·헤더·폼 배경 | `--navy-900`, `--navy-700` |
| 배경 / 카드 | 페이지 배경과 카드 색 차이 | `--bg`, `--card`, `--line` |
| 모서리 | 카드·버튼 둥글기 | `--radius: 20px`, 버튼 999px |
| 그림자 | 부드러운 큰 그림자인지 | `--shadow`, `--shadow-lg` |
| 글꼴 | 굵기 대비, 자간 | Pretendard, 제목 800, 자간 -0.03em |
| 모티프 | 반복되는 그래픽 (3D 큐브, 막대 차트, STEP 표시) | SVG로 직접 그림 |

**가져오지 말 것:** 레퍼런스의 이미지, 로고, 일러스트 파일, 문구. 모티프는 SVG나 CSS로 새로 그린다.

## 기본 토큰 (CutFlow — 레퍼런스가 없을 때 시작점)

```css
:root {
  --navy-900: #0b1222; --navy-800: #111b31; --navy-700: #1a2742;
  --blue: #2f6bff; --blue-300: #8fb2ff; --blue-100: #e7efff; --blue-50: #f2f6ff; --cyan: #5ccbf5;
  --grad: linear-gradient(135deg, #2f6bff 0%, #4a8dff 55%, #6fc3ff 100%);
  --bg: #f3f6fb; --card: #fff; --line: #e3e9f3;
  --text: #121a2c; --text-2: #4a5570; --muted: #8a94ab;
  --green: #1fb58f; --red: #ef4f5f;
  --radius: 20px;
  --shadow: 0 1px 2px rgba(17,27,49,.04), 0 8px 28px rgba(17,27,49,.06);
}
body { font-family: "Pretendard Variable", Pretendard, "Malgun Gothic", sans-serif;
       word-break: keep-all; overflow-wrap: anywhere; }  /* 한글 줄바꿈 */
```

AI 기능은 보라~파랑 그라디언트(`#7c5cff → #2f6bff`)로 일반 기능과 구분한다.

## 구성 요소 체크리스트

- **사이드바** (어두운 색): 로고, 워크스페이스 칩, 내비게이션 (활성 항목은 `--grad`), 하단 상태 패널
  - 상태 패널에는 음성 인식·AI 키·외부 도구 상태를 표시하고, AI 키 줄을 누르면 키 모달이 뜬다.
- **히어로**: 그라디언트 배경 + 오른쪽 SVG 모티프 + 흰 버튼(주 행동) + 유리 버튼(보조)
- **STEP 표시**: 어두운 바 위 `STEP1 … STEP4` 알약. 활성은 그라디언트, 완료는 청록 테두리
- **기능 카드**
  - 머리: 아이콘, 제목, 설명, 스위치
  - 본문: 옵션 (꺼지면 흐리게)
  - 꼬리: `이 기능만 실행`
- **AI 타일**: 잠금 상태면 자물쇠 아이콘 + `키 필요` 배지, 누르면 키 모달
- **하단 고정 실행 바**: 어두운 알약 모양. 선택 요약 + 주 버튼
- **처리 화면**: 어두운 카드 안의 진행 링(SVG `stroke-dashoffset`), 단계 목록(아이콘 + 진행 막대), 로그 콘솔(어두운 고정폭 글꼴)
- **결과 화면**
  - 수치 카드 4개 (첫 번째는 어두운 배경 + 퍼센트 배지)
  - 기능 실행 패널 ("편집" / "AI" 두 줄)
  - 캔버스 타임라인과 탭
- **모달**: 흐린 배경, 24px 모서리, 위쪽 그라디언트 아이콘, Esc로 닫기
- **토스트**: 하단 가운데 어두운 알약

## 반응형

- 1180px 이하: 4열 → 2열, 3열 → 1열
- 860px 이하: 사이드바를 서랍으로, 상단 모바일 바 표시, 여백 16px, STEP 라벨 숨김
- 확인: 375px 폭에서 가로 스크롤이 없어야 한다.
